## Instrument (whole run, not a sample)
- **A syscall interposer** (`…/scratchpad/qe198/probe/sockprobe2.c`, built with Apple clang 17). It is a dylib whose `__DATA,__interpose` wraps libc `listen()` and `bind()` and logs every call (pid, ppid, thread, rc, socket type, family, address), plus one `LOAD` line per process it is loaded into.
  - It is in-process, so it sees the main thread, every worker thread (`pool: "threads"`) and native code. It caught `esbuild` (Go) loading too.
  - **Count = successful `listen()` (TCP and Unix stream) + successful `bind()` on `SOCK_DGRAM` (UDP).**
- **Delivery without changing the command.** Homebrew's node 26.11.1 is ad-hoc signed (`flags=0x2`, no hardened runtime), so dyld honours `DYLD_INSERT_LIBRARIES`. SIP purges `DYLD_*` across `/bin/sh` and `/usr/bin/env`, so:
  1. A `node` shim first on `PATH` re-arms it before exec'ing the real node. Every `#!/usr/bin/env node`, `sh -c "node …"` and npm launch passes through it.
  2. The dylib also interposes `posix_spawn`/`posix_spawnp`/`execve` and re-adds the two variables to any child environment that dropped them (`env: {}` children).
- The command stays `npm test`, run as spelled in a fresh clone after `npm ci` (`…/qe198/a3` at `24f32527`).
- **Backstop:** an `lsof -i` / `lsof -U` sweep of the process tree every 0.2 s, with each process's ppid and args.
- **Calibration** (`probe/cal/`, outside any repo): main-thread TCP, a Unix-domain listener, UDP bind, a worker-thread listener, a `process.execPath` child, and an `env: {}` child. The probe counted 6/6 (5 `LISTEN` + 1 `DGRAM`).
