## Test-integrity: exit 2, and what that is

```

  Error: cannot read the registry file: .grugops/test-skips.md
  exit 2
```

Workflow 05 step 3 is explicit that exit `2` is *"the checker could not run … an error distinct from
a clean fail, recorded as such, never read as a pass"*. So:

- The checker **exists** (`tools/grugops/test-skip-integrity.js`); the **registry does not**
  (`.grugops/test-skips.md` is absent from this repo).
- This is a **pre-existing repo gap** — `ABC-013` did not introduce it, and the same absence is
  visible in the `ABC-018` and `EPIC-001` context notes.
- It is **not hiding anything on this ticket**: the skip count was measured independently by the
  `AGENTS.md` command and is **0**, so there is no skip for a registry to justify. A registry is
  owed the first time this suite skips a test, and a human owns it (`quality.test_integrity` is
  `warn`, and Workflow 05 makes the registry human-only in any case).

Recorded rather than silently rounded to green, which is the only reason the step exists.
