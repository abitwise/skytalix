# What the ELEVEN criteria actually admit, measured rather than read — and the measurement says more than the three reports did

The subtask said to take no role's count or characterisation on trust, and named why: this task has
already produced one confirmed miscount and one flagged non-defect. So each item was re-derived by
**evaluating the criteria as written** against every implementation that has been proposed for this
module — the delivered one and each mutant the Engineer and QE built. This note records what was
**measured**, separately from what was **ruled**, so the two are checkable apart.

## Method, stated so it can be attacked

The nine tuples were transcribed from the ticket's bullets — **not from the delivered test file**,
which is the whole point: the question is what the ticket *requires*, not what someone happened to
test. Each candidate implementation was then run against them. Criteria 10 and 11 quantify over
ambients the criterion does not fix, so they were evaluated over the **whole ambient space** the
wording admits: `isTTY` ∈ {true, false, **absent**} × each of `LC_ALL` / `LC_CTYPE` / `LANG` ∈
{unset, `C`, `en_US.UTF-8`, **empty**} — 192 ambients, and 11,232 ordered pairs that satisfy
criterion 11's own precondition that the rewrite would produce the other answer.

**`src/` was not touched to do this.** No mutant was applied to the tree and no test was edited; the
rule and the session were re-expressed outside the repository and driven from the ticket's text.
`git diff --stat -- src/` against the QE tip is empty.

## Result 1 — the nine tuples plus criterion 10 exclude exactly ONE of the eight proposed implementations

| Implementation | Excluded by criteria 1–10? |
|---|---|
| the delivered one | passes (correctly) |
| locale order `LC_ALL` > `LANG` > `LC_CTYPE` | **NOT excluded** |
| `LC_CTYPE` promoted above `LC_ALL` | **NOT excluded** |
| an empty variable counts as SET (the literal reading) | **NOT excluded** |
| the platform rule smuggled back in (`win32` → ascii) | **excluded** — by criterion 9 |
| session hardcodes `isTTY: true` | **NOT excluded** |
| session forwards only `LANG` | **NOT excluded** |
| session drops the flags | **NOT excluded** |
| session is lazy | **NOT excluded** |

Criterion 9 — the `win32` regression guard — is the only one of the nine doing exclusion work beyond
the delivered behaviour. That is a fact about the criteria, not about the suite.

## Result 2 — criterion 11 is UNDER-DETERMINED, which is worse than "blind"

The Engineer and QE both reported criteria 10/11 as *blind* to a single-signal session. Measured, the
shape is sharper and it is a different defect class. Criterion 11 **never says which ambient values
the rewrite uses**, so it is not one criterion but a family, and its members disagree:

| Implementation | conforming instantiations that EXCLUDE it | that ADMIT it |
|---|---|---|
| session hardcodes `isTTY` | 2,592 | **8,640** |
| session forwards only `LANG` | 1,584 | **9,648** |
| session drops the flags | **0** | 11,232 |
| session is lazy | **0** | 11,232 |

**The first two are the under-determined ones**: whether criterion 11 catches a real production
defect depends on which ambient the test author happens to pick. **That is two readings of one
criterion — the exact defect this role ruled against on this very ticket at the `Backlog` exit, in
the section this role itself wrote.** The instantiation the delivered suite chose (both signals moved
together, `(TTY, UTF-8)` ↔ `(no TTY, LANG=C)`) is in the admitting majority, which is why the Engineer
found the survivors by mutation rather than by reading.

**The last two rows are not under-determination at all — they are absence.** No reading of criteria
1–11 can exclude a session that drops the flags, or a lazy one. A session that ignores `--ascii`
outright breaches table rows 1 and 2 and still satisfies every criterion, because criteria 1–3 test
the *rule*, which is handed the flags as arguments, and criterion 11 begins its session with no flags
at all.

## Result 3 — the LC_CTYPE rung, and a convention the file used two ways

Both reordering implementations satisfy all nine tuples, so QE's item holds. But the cause is not
that criterion 6 is "the wrong shape": criterion 6's stated job is the case-insensitive, hyphen-less
spelling, and it does that job. Two separate faults were found:

- **No criterion ever stated the middle rung.** Criterion 5 pins `LC_ALL` against `LANG`; nothing
  pins `LC_CTYPE` against either neighbour.
- **Bullets are silent about variables they do not name, and the file uses that silence two ways.**
  Under "silent = unset", criteria 6 and 8 are both fine. Under "silent = any value", criterion 6
  *would* have pinned `LC_CTYPE` > `LANG` — and **criterion 8 would be false**, since a UTF-8
  `LC_ALL` beats an `ISO-8859-1` `LANG`. Criterion 4 is the only bullet that quantifies explicitly
  ("regardless of locale"), which is what makes the inconsistency visible.

## Result 4 — POSIX, checked on this machine rather than recalled

The Engineer's empty-locale ruling rests on POSIX and was recorded at `confidence: medium` because
the ticket does not say it. The platform claim was verified directly:

- `env -i LC_ALL= LANG=en_US.UTF-8 locale` → `LC_CTYPE="en_US.UTF-8"` — **the empty `LC_ALL` fell
  through to `LANG`**;
- `env -i LC_ALL=C LANG=en_US.UTF-8 locale` → `LC_CTYPE="C"` — a **set** `LC_ALL` wins;
- `env -i LC_CTYPE= LANG=en_US.UTF-8 locale` → `LC_CTYPE="en_US.UTF-8"` — same fall-through one rung
  down.

The rule this ticket already describes in words is the one the platform underneath it implements.

## Checked and found FINE, recorded so nobody re-checks them

- **The absent-`isTTY` shape needs no criterion.** QE found it as a suite hole and closed it. Table
  row 3 says *"`process.stdout.isTTY` is **falsy**"*, and `undefined` is falsy — **the specification
  was already right**, and criterion 4 says "regardless of locale" which the ambient space above
  covers. No amendment is owed here and none was made.
- **The `Boolean()` comment defect is not BA/PM's and was not touched.** QE calls the comment false

- **Suite state re-derived, not inherited:** `npm test` gives **277 passed / 277 on 13 files**, with
  `src/glyph-mode.test.ts` at 21 tests. QE's and the Orchestrator's figures reproduce exactly.
