## Named blind spots (no row pins them; recorded, not owed)
- **Returning the null score** passes every behaviour row; only the source row reds it (the ADR names it).
- **At depth ≤ 5 every null child is a quiescence leaf** (remaining − 1 − 3 ≤ 0 below the root). So `A3`'s oracle, the mate
  floor and the door and instrument rows never search a null subtree. Only `A2`'s d8–12 rows and the frozen-clock counts do.
  That is the root of QE-208-a and -b.
- **A cut at a mate-valued beta** returns a mate bound. Probed: 0 null-only, shorter, longer or lost mates on the 287 and the
  190 at d5, in both recursions.
- `A1`'s two halves see different plants: the `A3`-corpus sweep sees the PVS-off search doors, and the six roots see the PVS-off
  engine door. A future cross-build check should keep both.
- `zugzwang.004` and `.005` (d11, d12) are deep-only. In the default lane only `.001` and the K+P rows police the guard's size.
