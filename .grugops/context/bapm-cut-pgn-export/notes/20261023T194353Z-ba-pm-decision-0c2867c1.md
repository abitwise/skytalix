# ABC-203 cut: automatic PGN at game end, under `games/`; EPIC-006 records PGN export in scope

**Ticket:** `plans/tickets/ABC-203-at-game-end-npm-run-chess-writes-the-game-as-a-standard-pgn-file-under-games.md`. Ready, size M (3), priority P1, DoR 10/10. An Architect/Design ruling comes first, then SE, QE and Security/NFR.

## Rulings
1. **When.** The file is written automatically, with no command and no flag. Exactly one file is written when the loop returns a non-null `reason`: the eight chess outcomes (resignation included) and the two engine faults.
2. **When not.** No file on a confirmed `quit`, end of input, usage error or internal error (70). These paths stay byte-identical to base. `resign` keeps a record and `quit` leaves without one. An unfinished game is save/resume's job, and save/resume waits on the play-test. This rule also needs no quit-vs-EOF split, so there is no `turn-loop.ts` change, and the existing quit/EOF pins and the ABC-201 piped reading are untouched.
3. **Where and name.** `games/skytalix-YYYYMMDD-HHMMSS.pgn` under the process cwd, which is the clone root under `npm run chess`. The name uses local time from one clock reading at game start, which also gives `Date`. `.gitignore` gains `games/`.
4. **Overwrite.** Never. The write is an exclusive create, with suffixes `-2`…`-99`. If all are taken, it fails with EEXIST.
5. **Tags.** Ten, in this order: Event "skytalix CLI game", Site "?", Date, Round "-", White, Black, Result, Termination, Difficulty "N", HumanColour. The human's side is "Human" and the engine's is "skytalix (difficulty N)". No SetUp/FEN.
6. **Results.** 1-0, 0-1 and 1/2-1/2 take Termination "normal". A fault gives `*` and "unterminated".
7. **Movetext.** SAN via `toSan`; `N.` before White moves; a closing `{headline}` comment (which keeps claimed vs automatic, the epic's amendment); then the result token. Lines are ≤ 79 characters, LF only, ASCII 0x20–0x7E.
8. **Failure.** The result screen is unchanged. stderr gets one line, `PGN not saved: <errno code>`. Exit 0 and no partial file.
9. **Success.** stdout gets one extra line after the screen: `PGN saved: games/<name>`.
10. **Oracle.** A7 matches the game-1 sample's movetext byte for byte (whitespace normalised), and A6 round-trips through `parseSan` to an equal FEN.

## Risk triggers
- **Security/NFR hop owed.** This is the CLI's first file write. ADR-0036 (b1) limb 1 and (b2) are expected to fire. 0 user-controlled path bytes; exclusive create; errno-only stderr. A `games` symlink to a directory is followed, and Security/NFR rules on that.
- **NFR-008:** +1 test file and a target of 0 new spawns.
- **NFR-007 and NFR-002:** untouched (A12).
- **Cost:** build plus write ≤ 50 ms wall, max of 5, at 300 plies, one QE reading.
- **Postures:** ADR-0007 and ADR-0018 are unaffected.

## Architect questions
1. Module shape: formatter, fs-limb writer, wiring. Keep `history.ts` a type-only import (ADR-0002 clause 4), and decide how the headline reaches the comment.
2. Keep the tree clean under `npm test`: spawned children that reach an outcome run with cwd = tree root. No argv or env may reach the production path.
3. The clock seam.
4. Whether an ADR is needed.

**STOP** goes to the owner only if an accepted ADR is reversed. BA/PM sees none reversed (ADR-0007, ADR-0018, ADR-0011 clause 4, ADR-0036).
