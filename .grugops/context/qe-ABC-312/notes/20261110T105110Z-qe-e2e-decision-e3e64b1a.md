## Gaps
- **G1, BLOCKING: an En Croissant over-claim.** README.md line 151 reads "Tested by the owner on 2026-11-10. The Windows launcher is untested." The steps below it say "select the launcher: `<clone>/bin/skytalix-uci`". Together they tell the reader that the owner tested these steps with this launcher. He did not: his 2026-11-10 run used a launcher he made himself, before bin/skytalix-uci existed (the SE note says so too). The Cute Chess section draws this same line ("Running dist/uci.js directly was tested there; the launcher has not been tried in Cute Chess"). The En Croissant section does not. Exact fix: replace line 151 with:
  "The owner ran skytalix in En Croissant on 2026-11-10 through a launcher he made himself, before `bin/skytalix-uci` existed. **These steps, with the launcher in `bin/`, have not been tried in En Croissant.** The Windows launcher is untested."
  This is a README-only change. Re-check: the art cmp, lint, and the line-151 text.
- **G2, low: `/usr/bin/node` comes before nvm.** A2 lists /usr/bin last. The script checks /usr/bin/node in its first loop, before the nvm glob. In practice a GUI PATH that holds /usr/bin finds the system node through `command -v` first anyway, as A2 prescribes. So an old distro node, for example Ubuntu's apt node 18, shadows a newer nvm node either way. Suggested fix: drop `/usr/bin/node` from the first loop. After the nvm loop, add `if [ -z "$node" ] && [ -x /usr/bin/node ]; then node=/usr/bin/node; fi`. Also say in the README that a GUI uses the first node on its PATH.
- **G3, low: nvm picks by name order (shown in c11a).** With v22.9.0 and v22.18.0 installed, it runs v22.9.0, which is below engines ">=22.18". "v9.x" would also beat "v22.x". The SE marked this as a shortcut. Suggested fix: pick the highest version numerically, for example `best=$(ls "$nvm_dir" 2>/dev/null | sed -n 's/^v\([0-9]*\)\.\([0-9]*\)\.\([0-9]*\)$/\1 \2 \3 &/p' | sort -n -k1,1 -k2,2 -k3,3 | tail -n 1 | cut -d' ' -f4)`, with `nvm_dir=${NVM_DIR:-$home/.nvm}/versions/node`. Or read nvm's alias/default first.
- **G4, low: a symlinked bin directory fails (c3e).** Running `linkdir/skytalix-uci`, where linkdir -> <clone>/bin, exits 1 with "dist/uci.js is missing", because a logical `cd` resolves `linkdir/..` lexically. Fix: change line 15 to `cd -P --`.
- **G5, low, UNKNOWN - verify: the .cmd fallback under a 32-bit GUI.** A 32-bit process sees `%ProgramFiles%` as "C:\Program Files (x86)", so the fallback misses a 64-bit Node in "C:\Program Files\nodejs". QE believes Arena 3.5.1 is 32-bit, but has not verified it. This matters only when node is not on the PATH. Suggested fix: before the %ProgramFiles% line, add `if exist "%ProgramW6432%\nodejs\node.exe" set "NODE=%ProgramW6432%\nodejs\node.exe" & goto run`. Trivial: each echo line prints a trailing space before ` 1>&2`.
- **G6, low: macOS is claimed but unrun.** README line 85 says that on macOS and Linux the launcher "finds `node` even when the GUI starts it with a short `PATH`". QE read the macOS path by inspection only. Suggested: add "It has been run on Linux only."
- **G7, low, UNKNOWN - verify: the asdf shim may fail under a GUI.** An asdf shim may need `asdf` on the PATH and a global version. If the shim then fails, the launcher does not fall through to nvm.
- **Not run:** shellcheck (absent), macOS sh, Windows cmd, and any GUI with the launcher.
