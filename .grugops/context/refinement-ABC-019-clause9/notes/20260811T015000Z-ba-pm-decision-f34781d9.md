## The two criteria, and what each one is for

**`A18` (clause 9d) — two stub shapes, neither at the reference layout's 3 and 8.** Four measurable
clauses: (i) no stub's status count is 3 and no stub's history count is 8; (ii) one shape at
`H` ≤ 24; (iii) one at `H` ≥ 25; (iv) on a 24-row TTY sink `beginFrameSession` therefore chooses
in-place for the first and append for the second, both observed on the emitted stream. Reference
pair, measured: 2/5 → 19 in-place, 4/9 → 25 append.

**`A19` (clauses 9a + 9e) — the session-height invariant, in four clauses:** (a) `beginFrameSession`
called **exactly once**; (b) the height it is given **equals the first frame's `.length`**; (c) every
frame reaches the writer **unmodified**; (d) **every** frame's `.length` equals that one height.

## The three rulings this hop had to make

1. **`A19` carries FOUR clauses, not clause 9e's one, because clause 9e's literal words are GREEN on
   a wrong build.** Measured: a loop that pads or truncates every frame to its height satisfies
   *"every frame's length equals the session height"* while **truncating a 20-row frame to 19** — it
   eats the reserved prompt row. And a loop that calls `beginFrameSession` per frame satisfies (b),
   (c) and (d) while re-choosing the strategy `src/frame.ts`'s header rests on choosing once. **9d
   does not save 9e on its own.** Each clause was kept only because a build defeats the others
   without it; none is symmetry.

2. **The two stub shapes are FORCED, and by a stronger argument than the ADR's.** `ADR-0009` 9d wants
   the pair so the append branch is exercised, which is true and sufficient. Measured here: with one
   shape a **tuned literal** (`H` = 19 against a 2/5 stub) is green on every clause of `A19`, so the
   landmine is simply re-armed at a different number. **Two shapes whose heights differ cannot both
   be satisfied by any literal**, so the derived form is the only build that passes — measured row by
   row across `H` = 23, 19, 25 and derived. That is why `A18` states constraints plus a reference pair
   rather than the pair alone: any pair meeting (i)–(iv) buys the same property.

3. **The 13 scripted-game rows run under shape A only, and that is a budget ruling, not a shortcut.**
   The terminal verdict and the frame count are **identical under every shape** (Fool's mate is
   `black-wins`/`checkmate` at H 19, 23 and 25; 14 frames for 12 plies + 1 non-advancing outcome
   under all six geometries), so re-running the table under shape B asserts nothing new and spends
   `N8-LANE`. Shape A is the default for the whole table precisely so a hardcoded height is red
   across it rather than in one test.
