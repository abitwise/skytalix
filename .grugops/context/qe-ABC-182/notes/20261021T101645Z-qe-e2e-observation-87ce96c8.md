# ABC-182 QE gap register: QE-182-a (LOW), -b (INFO), -c (INFO), -d (INFO). None is against a criterion, and none blocks (`security.block_on` is `high`)

- **`QE-182-a` (LOW; route Architect/Design, the instrument's owner; fold into the next ticket that edits
  `r2-mutants.sh`, e.g. `AR-163-DELONLY`'s fix).**
  - **The defect.** A plant with two substitutions passes under its full label when only one applies. `mk` refuses a
    plant only when nothing changed.
  - **Demonstrated on P2c.** The drift commit `14989ee2` (scratch clone) makes `cli.ts`'s `read: readBookFile,`
    no longer match. The harness then exits 0 with `P2c … path: string, from cli.ts options … ok`, on a plant that
    touched only `src/book-file.ts`. P2c's distinct claim is lost silently: a changed caller does not add `cli.ts`
    to the Ruling 2 list.
  - **The other plants.**
    - X1: if only the import drop applies, it still reads as a base-only plant. If only the return change applies,
      the R2 list becomes `@<base> and <head>` and the row turns red.
    - G1-GRD's base edit is a single substitution, so it is not exposed this way.
  - **Today:** none. At `19abbdb1` and `053595af` every edit applies (QE read all 8 plant diffs).
  - **Trigger:** any `src/cli.ts` or `src/book-file.ts` edit that moves the matched text.
  - **Fix shape:** check that each `ed` changed its own file, or assert the plant's `--name-only` list.
- **`QE-182-b` (INFO; route Architect/Design, records).** Exit 1 is shared by "a row mismatched" and "the instrument
  could not run". A relative instrument path gives rc 1 with no plant named and an empty sha in the header: node
  fails after the `cd` into the clone, and `set -e` stops the run. The usage line asks for an absolute path, so this
  is misuse, but the header documents exit 1 as naming plants. **Reading rule until fixed:** an rc-1 run must end
  with an `r2-mutants: limb 1 MISMATCH` or `DIFFER` line, or it is a harness failure, not a verdict.
- **`QE-182-c` (INFO; records only, by design).**
  - NOH's `adds nothing` is enforced only when a `(b1) Ruling 2` line is printed. The SE chose this so that A3
    names exactly 4 (`…c8d1c57c`), and QE agrees it is needed for A3.
  - Two things the harness does not check:
    - the Architect's "runs no pathspec diff" property for NOH (ABC-163 QE read it with a git shim);
    - the `(b1) capability` count (printed, not compared).
  - A future instrument could drop the no-holder message alone and keep NOH green. That is narrower than the SE's
    "drops the line" case, which P2b, P2c, CMT and X1 catch.
- **`QE-182-d` (INFO; route BA/PM, page wording only).**
  - **A1's wording.** A1 says `git diff --name-only <base>` lists exactly 2 files. At the tip it lists 5 (the SE's
    3 notes). QE ruled it MET on intent.
  - **The Scope's wording.** Scope item 2 says `r2-mutants.out.txt` is "the output of the first run at `A3`". A5
    and the committed file say it is A2's green run. The file is right; the Scope wording is the slip.
  - **Suggestion for future pages:** scope file-list criteria to the code commit, or exclude
    `.grugops/context/<task>/`.

**Not a gap:** the SE's waiver reading used the range form. QE added the per-commit form; both are empty.
