## `[D42]` / `A10b` — the one that moves the board, and why it went this way

`A10` names the **engine** seam and nothing else, so nothing guarded the input seam and the delivered
loop plays a move no generator produced. **Ruled: the loop guards BOTH seams.** Four reasons, in the
order they bind:

1. **The owner's standing directive is directly on point** — *"The most important thing is that chess
   moves are legal according to game rules, everything else comes after that"* (Olger Oeselg,
   2026-07-31, the directive already recorded in this ticket's `## Out of scope` amendment, where it
   **overturned a previous BA/PM ruling**). "A later epic validates it" is the *everything else* that
   directive puts second.
2. **Measured at this hop on the delivered build.** Not generated, applied regardless, ply counted,
   resulting position unreachable by any legal move.
3. **`[D31]` already ruled this loop must not assume that seam is well-behaved.** `## Scope` justified
   the missing guard only by a property of the **stub** — a statement about the test double, not about
   the `InputSeam` contract `EPIC-003` replaces it under.
4. **THROW, not terminate, and not `rejected`** — and the shape is `A9b`'s, not a new invention. A
   `{kind:"move"}` that is not legal is a **parser bug**, not a user typo; a real parser reports the
   user's illegal move as `rejected` itself. Converting it to `rejected` presents a broken parser as a
   typo forever. Terminating with a named reason would invent a tenth `A14` value and decide *does a
   parser bug end the game?* — which `[D31]` handed to `EPIC-003`/`EPIC-006` **on this very seam**.
   Reusing `engine-failure` would report an input fault as an engine fault. **`A14` is untouched.**

**Cost:** one membership check over the six-field comparison already at `src/turn-loop.ts:264-272`,
plus a throw. Zero new modules, imports, terminal-reason values or signature changes. One test row.
**`N8-LANE` does not move — no new test FILE.**

## `[D38]` / `G-6` — ruled ONE way, and the way is forced by a TYPE

`## Scope` transition 15 required *"the terminal frame has been shown"*; `A2` and rows 12/13's
`frameCount: 1` forbade it. **`A2` stands and the trigger is reworded.** The decisive fact is not a
preference: **the render seam takes a `GameStatus`, and a terminal `GameStatus` requires
`reason: EndReason`** (`src/gameend.ts:57-69`, read at source). `engine-threw`, `engine-failure` and
`resignation` are members of this loop's `TerminalReason` and of **no** `GameStatus`. **On edges 12,
13 and the prompt-driven outcome the loop cannot construct a terminal frame at all** without editing
`src/gameend.ts`, which `A14` forbids.

**QE's player-visible reading is correct and is not disputed** — the game ends and nothing on screen
says so. What is ruled is **where that is owed**: `EPIC-006`'s result screen, which is
`## Out of scope` by name and which `A10`'s own rationale presumes exists. Emitting a second frame
here would repeat an `in-progress` board with the thinking flag cleared — it would **not** make the
screen say the game ended, and it would cost `A2` its arithmetic. **The residue is handed to
`EPIC-006` as a named input (flag 12), not buried.**
