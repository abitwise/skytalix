# The sweep: FOUR more falsified statements beyond the flagged line, all one defect — plus three that are still TRUE, one the fix REPAIRS, and one that was already false before this branch existed

The brief said the count on this ticket has always been a floor and that the job was the sweep, not
the one line. It was swept. **The flagged line was not alone, but it is also not five separate
defects: sites 3-7 all rest on ONE premise — *the generator is unsound outside the domain* — and this
fix removed that premise.** Every verdict below was measured on tree copies outside the repository,
never read off a file.

## Falsified, inside `src/` — `A11`'s remit

| # | site | the statement |
| --- | --- | --- |
| 3 | `src/legal.ts` **69-70** | *"Outside it the oracle is unsound — `generateMoves` offers en-passant captures onto squares occupied by the mover's OWN piece"* — the trigger, confirmed |
| 4 | `src/legal.test.ts` **268-269** | *"because `generateMoves` is itself unsound there and the oracle cannot be the authority on a class it gets wrong"* |
| 5 | `src/legal.test.ts` **368-371** | *"the one where `generateMoves` offers an en-passant capture onto the mover's OWN piece"*, and *"the oracle agreeing with the relaxed guard is not a defence"* — the oracle no longer agrees with the relaxed guard; it now agrees with the SHIPPED one |
| 6 | `src/legal.test.ts` **373-374** | *"The oracle answers `true` on all four … off-domain the oracle is unsound"* — measured `true/true/true/true` on `main`, **`false/false/false/false`** on the tip |
| 7 | `src/moves.enpassant.test.ts` **4-9, 27-28** | the header's present-tense *"the generator offers a capture onto the mover's own piece"* and *"a board the generator provably corrupts"* |

**`src/legal.ts` now contradicts itself 33 lines apart.** 69-70 says the generator offers the capture;
the `A11`-corrected 102-107 says it does not and explains why. That is the sharpest statement of the
defect and it needs no measurement to check.

Site 7 is the lowest-severity of the five and I say so rather than levelling them: it is a
red-before-green header whose subject IS the defect, not a doc comment describing the shipped design.
But `src/moves.ts:183-195` — the same engineer, the same hop — is written in the **past** tense for
exactly this reason, so the standard is the project's own and is applied consistently. Measured on the
delivered tree, `4k3/8/8/8/3pp3/8/8/4K3 b - e3 0 1` yields **0 ep moves offered and 0 make/unmake
pairs that fail to round-trip**, against 1 and 2 on `main` — so *"a board the generator provably
corrupts"* is false.

## NOT falsified — re-measured TRUE and fenced against rewrite

This is the `104-105` trap and the sweep found three more of it. An engineer told to "fix the false
comments about the generator" would plausibly break each one:

- **`src/legal.test.ts` 286-289** — *"`generateMoves` reads an occupied ep target as an ordinary
  capture and never offers the ep move"*. **Still true**, because those two rows carry **ENEMY**
  occupants, which the ordinary-capture branch consumes and `continue`s past exactly as before. This
  sentence sits 80 lines from site 4 and says almost the same words about a different class.
- **`src/legal.ts` 108-109** — *"Purity does NOT need it"*. Confirmed: with guard (a) deleted,
  `hasLegalEnPassant` stayed **pure on all 100,801 scored states**; with guard (b) deleted it is
  impure on the **first** state swept.
- **`src/legal.test.ts` 279-280** — *"Each one corrupts without it, permanently"*, a claim about the
  predicate without guard (b). True.
- **`src/zobrist.ts` 11-18** and `ABC-022`'s own `## THE CORRECTION THIS TICKET CARRIES` — both
  re-derived here and both intact. The four-row table in that section reads identically on `main` and
  on the tip, which is precisely what it claims of itself.

## One statement this fix REPAIRS

`ADR-0005` clause 6 says *"(b) buys purity, **(a) buys agreement with the oracle**"*. Pre-fix that was
loose-to-false: on the own-piece class the oracle answered `true` and guard (a) made the predicate
answer `false`, so (a) bought **disagreement** with the raw oracle. Post-fix the oracle answers
`false` there and (a) is what keeps the predicate with it. **The fix makes that clause exactly true.**
A sweep that only reports damage is not a sweep, so it is recorded.
