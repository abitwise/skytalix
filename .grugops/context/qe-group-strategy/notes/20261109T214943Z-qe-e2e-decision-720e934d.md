## The rules for every group

1. **Branch.** One branch per group, `grugops/grp-<letter>`, cut from `main` when the group starts. Behind-counts are
   measured at `21aa34ad` (`git for-each-ref` ahead-behind against `main`): 43 to 2 449. The brief's "42 to 2 378" was
   read one commit earlier and left out the remote branch. A kept branch **≤ 300 commits behind** gets one `git merge` attempt. Any conflict under
   `src/` aborts it, and that member is re-ported. A branch **over 300 behind** is never merged. Its member is
   re-ported from its ticket page, with the branch read as a reference only. A member with no code is a new build
   from its page. Moved tests are re-pointed, never copied with old figures. Each member keeps its own off door, and
   the all-off door is node-identical to `main` (`ADR-0056` bundle read, R-BUNDLE-1).
2. **Untimed gates first**, under the host lock on one core, no held host needed. In order: lint, typecheck, build;
   the default lane with **one vitest worker** (spelled in the PREREG; plain `npm test` runs two); perft deep where
   the group touches the rules core; node identity (`G4`, the all-off door against `main`; the whole tree where the
   group claims value identity); the deep lanes the group touches; zugzwang 7 / 7, mate floor 0, `G1` ≥ 54 / 58 with
   none newly missed. Read all-on first, then per member on a red. No game or timing runs until every gate is green.
3. **QE's freeze and PREREG are sealed before the build is dispatched**, as the four missed freezes taught
   (`ABC-228`, `ABC-274`, `ABC-289`, `ABC-291`).
4. **The graded read runs in held-host windows.** W is asked of the owner for each window and never inherited, with
   `ps` checked first. **T1:** C2′ alone, about 30 min with two builds. **T2:** S′, the Levels lane, `G6` and the
   `G8` read, about 35 min. Each window stays under 1 h. One a group, never pooled.
5. **No SPRT. 100 games per group.** A group counts as one change. Never extended. A stale read (another group merged
   under it) is read again on the new base, as C2′'s stale rule says. That is not a re-play.
6. **On a miss.** A miss is NOT MET, is never re-played, and gets a `failed-attempt` note.
   - **Before any graded read:** one untimed diagnostic may name a single member to drop. It is a per-member door read
     of the red gate rows, counts only, no clock, no game. It names a member only if that member alone fails while
     the rest pass. The gates then run again on the smaller group. This is pre-registered in each group's PREREG. It
     is not a re-read, because nothing graded has run.
   - **After a graded miss:** the same diagnostic runs on the group's own rows. Where the table says "yes", one re-read
     without the named member is allowed. It must be pre-registered before the first graded game. It is a new
     100-game read with the same bar, at most one per group, and its own miss is final.
   - A score miss where every member's rows pass names nobody. The group closes NOT MET.
7. **The base.** Each read's base is its merge-base on `main`: R2's `main`, plus the groups that passed and merged. A
   group that misses never enters a later base.
