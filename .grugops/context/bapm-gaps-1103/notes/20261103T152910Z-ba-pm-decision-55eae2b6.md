# bapm-gaps-1103: ABC-278 cut (the records path check hardened; S, P2, DoR 10/10, Ready); QE-276-a/b accepted LOW on ABC-276, not folded

Authoritative text: the `ABC-278` page `## Scope`, `## Out of scope` and `## Acceptance criteria`. This note gives the routing and the reasons; it does not restate the rows.

- **Cut: `ABC-278`**, EPIC-011 records hygiene (outside the phase order, like `ABC-276` / `ABC-277`). Size **S**, upper end, and priority **P2** are the Orchestrator's brief. **DoR 10/10, Ready**; the column move is the Orchestrator's. Code paths: `tools/grugops/records-path-check*.js`, plus one line of `memory-bank/70-runbook.md`.
- **Routing, one acceptance row per QE gap (qe-ABC-277 `…7d149fbd`):**
  - **QE-277-a, MEDIUM → A1.** The added-lines diff reads as text (`--text` or an equivalent). Four runs exit 1 with equal finding sets: root `.gitattributes` set to `*.md -diff` and to `binary`, each from the branch checkout and from main's. A NUL-byte record is read. `$GIT_DIR/info/attributes` is covered. **Declined: QE's alternative of flagging a `.gitattributes` change as a finding.** Once the diff reads as text, attributes no longer change what is read, and a legitimate `.gitattributes` has no placeholder remedy, so the flag would block every merge that adds one.
  - **QE-277-b → A2.** `.xz` is decompressed with `xz -dc` (no shell, 256 MiB cap). A missing or failing `xz` gives one `UNKNOWN - verify (cannot decompress)` finding and exit 1, which fails closed as a corrupt `.gz` already does. An R100 move gives exit 0. Other archive forms are out of scope, with a re-open trigger (one committed under the three paths).
  - **QE-277-c → A3 and A4.** A3 adds five shapes (flags before the absolute path; `python3 -u`; a lone absolute executable at the end of a line or inside brackets; `ps -ef`; `ps aux`) and keeps both existing exclusions. A4 sets a false-positive budget, measured at base: **≤ 10** newly hit non-process lines, counts and classes only. This is the split point if the ticket grows.
  - **QE-277-d → A5.** `<home>.`, `<home>-…` and `<home>_…` hit, and `<home>2/x` stays clean. **Declined: the JSON `\/` half (INFO).** Node and Python JSON writers do not escape `/`, and there are 0 such lines at main. Re-open trigger: a record writer that escapes `/`.
  - **QE-277-e → A6.** Quoted names print clean (a TAB or space in the name). A direct `unquote` row closes the coverage hole.
  - **QE-277-f → A7 and A8.** The brief owed only a runbook line, and A8 is that line (the real `HOME`). **BA/PM added A7:** the home classes are also built from `os.userInfo().homedir` when it differs, so an override cannot narrow the check. A line of text depends on the operator remembering it; this costs a few lines in the same file.
  - **"Still exits 0 on main" → A9.** The ticket's own branch exits 0 with `--base main`, and `--head main` exits 0. The PR also reports the result over ABC-277's merged branch (`541ddf45^1..541ddf45`); 0 is expected but was not read by BA/PM.
- **QE-276-a and QE-276-b (qe-ABC-276 `…1cbc2325`): accepted LOW on the `ABC-276` page, each with a re-open trigger, not folded into `ABC-278`.** Reasons:
  1. Both live in `tools/rating/`. Folding them gives `ABC-278` a second file set and a second QE reading, which breaks INVEST "independent" and "small".
  2. QE-276-a's only row that sees `main()`'s call site runs `rating.ts r` with fake tools. That costs a clone, `npm ci` and a build per run (about 450 MB and 3 s, QE), so it is not cheap. The code is right today (10 real runs), and QE's next r/d grep is a second net.
  3. QE-276-b is inherited from `rpair` (`ABC-225`), whose byte-equal net (`ABC-225` / `-247` / `-255` / `-275` rows) a redaction change would put at risk. It cannot occur on this host.
  - **Triggers:** (-a) any diff to `rating.ts` `main()`'s r/d path, or a failed `sha256sum -c` or placeholder grep at a QE r/d reading; (-b) r, d or rpair run on a host whose user or host name is under 3 characters, or equals a placeholder word or `skytalix`.
- **QE-276-c (INFO)** goes to QE at the next r/d reading. **QE-276-d (INFO)** has no owner; `ABC-277`'s home-slug class is the net. **QE-277-g (INFO)** is accepted by QE and unchanged.
