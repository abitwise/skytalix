## A5 (`G2`)
- **Arms**, all imported into **one** `node` process per session, each from `git archive` into its own scratch dir (deleted afterwards):
  - **B, the base (pre-ticket head):** `main` `54dee3f2`, `src/` tree `4d6b117b`. At seal time `main` is `af214979` and `git rev-parse main:src` is still `4d6b117b`, so B is the `main` the build sits on. Entry: `evaluateAtPhase`.
  - **C, the control:** the same tree, second dir. Entry: `evaluateAtPhase`.
  - **H, the graded arm:** `grugops/ABC-274` at `2baeb905` (code commit `7daae342`, the S1–S3 repair; `src/` tree `4cb84035`). Entry: `evaluateAtPhase`, the function the three tapered call sites call (`search.ts` leaf and futility, `quiescence.ts` stand pat; read in the copy). Read on the repair head itself, so A5 does not lean on the carry-over condition.
  - **P, a report:** `main`'s pre-E1 `src/` tree `58fa3eb4`. Entry: `evaluate` (it ignores the phase argument).
- **Instrument (`g2q.ts` / `g2b.ts` shape):** the six perft roots; N = 200 000 calls per root per round; 6 rounds. **Round order in words:** rounds 2, 4 and 6, counted from 1, reverse the session's arm list; round 1 is the dropped warm-up (the script's `r % 2` on a 0-based `r`). Each arm's statistic is the mean over rounds 2–6 of its mean over the six roots, in ns per call. Every arm is called `ev(position, phase)` with `phase = phaseOf(root)` (H's) computed once per root before timing; no wrapper closure; a running sink.
- **Session order (`ADR-0031` d3):** session 1 lists **[B, C, P, H]**; session 2 lists **[H, P, C, B]**.
- **Statistic and verdict:** r_s = mean(H) / mean(B); **R = (r₁ + r₂) / 2; MET iff R ≤ 1.0500**, compared unrounded, printed to 4 dp. No third session, no tie-break.
- **Void rule, on C alone:** c_s = mean(C) / mean(B) outside **[0.970, 1.030]** voids that session. It is re-run once, in its own recorded window, in the same order. A second void in the same slot is a **STOP to Architect/Design** with every reading attached: no verdict and no further session.
- **Nothing else voids, adds or drops anything:** no load threshold, no extra session or round, no dropped root, round or outlier, no re-read after a verdict.
- **The spread, stated ahead as a report (grades nothing):** each r_s, |r₁ − r₂|, and each arm's per-round min–max over rounds 2–6, against `qe-ABC-269`'s reference spread **0.037** in r. If |R − 1.0500| ≤ 0.037 the verdict line adds "within one session spread". MET stays MET; a miss stays a miss.
- **Host, per session:** under `flock …/host-test.lock`, one core, ALONE (nothing else of QE's running; foreign vitest / cutechess checked before each session); recorded: `date -u` start and end, `uptime` (load1) at start and end, `node --version`, the trees.
- **Reports (not graded):** c_s and H / P per session (the cost E1 and E2-pre add together against `58fa3eb4`).
- **S2 nps report (ruled report-only, `…690d3b30`; never grades):** right after each session, in the same lock hold: `chooseMove` to depth 8 on a frozen clock, kiwipete and position-6; arms H, B and P `chooseMove`; 3 rounds alternating, round 1 dropped; ns per node and the ratios H / B, H / P. Node counts are printed; H's and B's must equal B0 (a mismatch would be an A1 defect, reported as such). Beside it, nodes / ms at 4 000 ms from A6's own runs. The ≈ 1 h formal S2 protocol is not taken: the ticket asks only that "the nps figure is reported".
