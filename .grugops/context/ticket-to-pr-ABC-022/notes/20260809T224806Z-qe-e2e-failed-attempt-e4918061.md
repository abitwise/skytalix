# Two instrument failures at this hop, both caught before they became verdicts — the `A7` walk counted the wrong population, and a mutant did not compile

## 1. The `A7` walk counted LEAVES, and the ticket's figure counts VISITED NODES

The first version of the walk returned `1` at depth 0 and summed, which is classic perft. It produced:

```
startpos d4 197281 · kiwipete d3 97862 · position-3 d4 43238 · position-4 d3 9467
position-5 d3 62379 · position-6 d3 89890      TOTAL 500117
```

Every one of those is the correct **published leaf count**, and every one is the wrong number for
`A7`. The ticket's `206604 / 99950 / … / 518474` counts **every node visited, root and internal
nodes included**. The two differ by exactly the non-leaf population: `518,474 − 500,117 = 18,357`,
which is the same 18,357 the engineer's own failed-attempt note names as the nodes that call
`legalMoves`.

**How it was caught rather than published:** the `nodes with epSquare set` line came out at `81,397`
— matching the ticket exactly — while the totals did not. A sub-count that matches on a total that
does not is a population error, not a behaviour difference. Fixing the walk to count visited nodes
reproduced all six per-root figures exactly.

**The lesson worth carrying:** *"perft total"* and *"nodes walked"* are two different numbers on this
project and both appear in `ABC-022`'s prose. `A7` is the walked population; `A8` and `npm run perft`
are leaf counts. A harness that reports one under the other's name will look wrong by 3.5% and be
right about nothing.

## 2. A mutant that did not compile, and it would have read as a spectacular red

The first build of the "some ENEMY piece is behind it" mutant replaced the guard block including its
`const capturedPawn` declaration, while the `moves.push` below still referenced it:

```
src/moves.ts(203,21): error TS2304: Cannot find name 'capturedPawn'.     tsc exit 2
```

Had the campaign run tests before typechecking, that tree would have failed everything and been
recorded as "the criteria catch it" — the exact false reading this board records from `ABC-009`.
**Typecheck every mutant before believing any red** is not a formality; it fired at this hop, on this
role, on the very mutant that turned out to be the campaign's most important survivor once it
compiled.

Neither failure is a defect in the product, and neither changed a verdict.
