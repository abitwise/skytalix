## What WAS still wrong, and it is the thing the brief predicted rather than the thing it named

The brief said: **a repair is an untested claim, and that now applies to a sentence written inside a
repair block.** It does. *"The seam is not new and its RETURN does not change"* is true but
**unanchored** — it never says what the return is unchanged *from*:

- read against **this ticket's own text**, it is **vacuous**: `[D27]`'s own first sentence says
  `readonly string[]` *"appears nowhere in this ticket's previous text"*, so there is no earlier value
  in the ticket for the return to be unchanged from;

That is the same failure shape as the original — an unanchored *"does not change"* in a repair
block — with a different clause carrying it. **Repaired (`[D49]`)** so it states its baseline, cites
the seam at source, and carries the fourth argument's qualifier in its own words. That last part is
not decoration: **this is the sentence that was already lifted out of context into an ADR once**, and
a sentence that has been quoted alone must survive being quoted alone.
