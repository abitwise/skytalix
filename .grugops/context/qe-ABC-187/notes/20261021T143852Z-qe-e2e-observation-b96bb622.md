# ABC-187 A4: the page's pathspec is defective; the waiver measured in AGENTS.md's form is empty

- **Confirmed the SE's claim.** The page's `git diff --name-only main...HEAD -- src/ ':!src/**/*.test.ts' ':!src/__snapshots__'` prints `src/cli.test.ts`. Probe: `-- 'src/**/*.test.ts'` matches nothing, `-- ':(glob)src/**/*.test.ts'` matches `src/cli.test.ts`, and `-- 'src/*.test.ts'` matches it. Without `:(glob)` magic, `**/` is not "zero or more directories". The pattern needs a literal `/` after `src/` plus whatever `**` matches, so a top-level `src/*.test.ts` file can never match the exclusion.
- **The reference form** (AGENTS.md :150, ruled the reference on QE-159-f): `git diff --name-only main...HEAD | grep -v '\.test\.ts$' | grep '^src/'` prints nothing (grep rc 1). The same holds over the delivered range `94c4b510..9578481f`. The glob-magic form `':(exclude,glob)src/**/*.test.ts'` also prints nothing. 0 files under `src/__snapshots__` are touched. **0 production lines, so the zero-production-lines UAT waiver applies.** A waiver is not a signature.
