# ABC-216 QE findings and the first-time-visitor reading

**Reading for a first-time visitor:** it reads well. It is short (86 lines, 8 sections), each section answers one question, every fact matches the code, and every command runs. The rook-plus-wordmark title is tidy and fits in 64 columns. None of the findings below is blocking.

- **QE-216-a, MEDIUM, non-blocking. "Node.js 22 or later" is not enough for `npm run chess`.** The line equals `engines.node` `>=22`, so A5 holds. But `npm run chess` is `node src/cli.ts`, which needs native type stripping. That is on by default only from Node 22.18.0 / 23.6.0, as `ADR-0042` and `ADR-0044` both record. On Node 22.0-22.17, a visitor fails at Quick start's fourth command. This was not run on such a Node (the host has v26 only), so the failure is the ADRs' recorded fact, `UNKNOWN - verify` by a run. The fix needs `package.json`, which this ticket fences out. It is BA/PM's call: one follow-up that sets `engines.node` and the README line to 22.18 together, or the owner accepts the gap.
- **QE-216-b, LOW, non-blocking. No text title.** The optional `# skytalix` line is absent, so the name first appears as plain text at line 62. GitHub shows the repository name above the README. But a screen reader reads the art as punctuation, and GitHub's outline has no top entry. A minimal fix keeps the art as the visual title: put the name in the tagline ("skytalix: command-line chess against a club-strength engine."), or add `# skytalix` above the art. This is the owner's taste. The page made the heading optional.
- **QE-216-c, LOW, non-blocking. The colour default is not stated.** Line 42 says "Enter keeps the default", but the table gives a default only for `--difficulty`. The colour default is `white` (`resolveOptions`). Suggest: "`white` (default), `black` or `random`".
- **QE-216-d, INFO. Wording nits.**
  - In the Levels table, the row label "About" reads as a fragment. "Time per move" would be clearer, with "about" moved into the sentence above.
  - In the Licence section, "four grugops kit files" is a term a visitor does not know. It is `NOTICE`'s own heading, so it is acceptable.
  - The Development pointer sends a person to `AGENTS.md`, which is an agent contract. The page allowed this.
- **QE-216-e, INFO. Art provenance wording.** The eight wordmark letters match the FIGlet "standard" font's lowercase glyphs letter for letter, joined with one space. The SE note says "drawn by hand … not generated by a tool" in that idiom. A3 holds either way: a font's glyphs set for this file count as generated for this repository, and the note names the FIGlet standard idiom. Still, the record would be truer as "FIGlet standard glyphs, joined by a script; the rook drawn by hand". figlet is not on the host, so this is a reading against the font, not a byte diff. No source was found for the 7-line rook. Its originality is `UNKNOWN - verify`, low stakes.
- **QE-216-f, INFO.** A fresh `npm install` prints 381 B of `npm warn install-scripts` (esbuild, fsevents) on stderr, exit 0. A visitor sees it. This is not a README defect, and A4 sets no stderr bound on install.
