## The `A1` "not a deletion in disguise" ruling, asked for explicitly and given plainly

**Ruling: the deletion is WITHIN both the letter and the intent of the ticket. The criterion was
not read too generously, and it is not a stretch.** Three reasons, in the ticket's own words:

1. **The clause is in `A2`, not `A1`.** `A1`'s parenthetical is *"both directions, so the repair is
   not merely a bumped literal"*; `A2`'s is *"a repair that also loses this is a deletion in
   disguise"*. `A2`'s test is whether the `src/cli/main.ts` kill survives. **Measured: it does**
   (`M7`, 19 rows; `M4`, the nested equality alone).
2. **The ticket AUTHORISED this deletion in writing, in `## Scope`:** *"…or **delete the row** if
   the surviving assertions already carry it. **The engineer states which and why in the diff.**"*
   He deleted, and he stated it, in the commit message and in a seven-line replacement comment.
   A criterion cannot be read too generously when the scope names the exact move.
3. **`## Test notes` 2 draws the forbidden line and he stayed inside it:** *"Deleting the whole `it`
   block satisfies `A1` and fails this ticket's point."* The block is intact and still reds.

**Where the confusion came from, since it is worth naming.** The phrase is attached to `A1` on
**`plans/board.md:132`** — *"`A1` needs the red gone in BOTH directions so the repair cannot be a
deletion in disguise"* — and to `A2` in the ticket. The board's one-line gloss is the looser of the
two and reads as though `A1` forbids deleting anything; the ticket's `## Scope` says the opposite in
terms. **The ticket governs** (the board line is a summary, and this project's own one-line board
rule says so), so the ruling above stands unchanged. The board line is nonetheless a live trap for
the next reader and is worth correcting when that line is next touched — `G8`, cosmetic.

**One qualification for the record, which is not a mark against the ticket.** The ticket's premise
sentence — *"the count adds no discrimination to that purpose"* — is **true of the row's stated
purpose and false as a claim about the count's detection value in general**. The count was the only
assertion in the repository sensitive to the CARDINALITY of the flat module set, and its removal
lost one measured kill (`M2`). That is `G2`. It is recorded so that nobody later cites `ABC-103` as
proof that the count detected nothing — it detected exactly one thing, one file wide, and the
trade was still the right one.
