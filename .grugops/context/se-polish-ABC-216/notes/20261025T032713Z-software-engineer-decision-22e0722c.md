# Correction, 2026-10-25: how the ABC-216 title art was made

This corrects the "art" bullet of the earlier SE note `ticket-to-pr-ABC-216/…b31fcae0`. That note is in another task, so this note does not use `supersedes`.

- **Was:** "each letter drawn for this file, not generated by a tool".
- **Correct:** the eight wordmark letters are the FIGlet "standard" font's lowercase glyphs, set by hand. A scratch script only joined the rows with one space. The rook on the left is hand-drawn.
- **On the page:** the README credits the font in one line under Licence. FIGlet's standard font ships with FIGlet under its BSD-style licence. A3 still holds: the art is generated for this repository, and the method is named.
