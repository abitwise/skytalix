# The Engineer's five hand-offs adjudicated, and what is handed on from here

The Engineer's hand-over was read as **its framing of the risk, not a work order and not a
boundary**. Each item was re-checked against the code and the tests; two were extended past what it
asked, one was refused as not closable here, and none was taken on trust.

## The five, each with its verdict

1. **"The purity criterion has exactly one killer."** — **CONFIRMED and CLOSED.** The mutant that
   clears each square as it reads it was re-run: one killer against the delivered suite, exactly as
   reported. It now has **three**, and the new one compares the **raw 128-byte board** before and
   after on all 24 matrix cells, so it does not route through `toFen` — which reads only the 64
   on-board squares and was being asked to stand in for the whole array on a single FEN.

2. **"`a1`/`h8` dark now encodes a character CHOICE — three assertions plus two frames move."** —
   **UPHELD, and this gate made it worse on purpose.** Seven places now. The reasoning and the cost
   are in the `decision` note beside this one; it is named there rather than buried here because a
   reviewer who dislikes `:` and `.` deserves the real number.

3. **"22 of the 24 snapshots were not hand-verified."** — **CONFIRMED and CLOSED**, by a frame
   oracle derived from the FEN text rather than by hand-checking 22 more frames. All 24 matrix cells
   are now proven, not merely unchanged.

4. **"Nothing imports `src/render.ts` yet, so no test exercises it through a caller."** —
   **CONFIRMED and NOT CLOSABLE HERE**, and this is the honest limit of this gate. See below.

5. **"The `Position` is trusted; a bad board byte throws rather than drawing a placeholder."** —
   **VERIFIED TRUE** (bytes 7, 8, 15, 200 and 255 each raise a `TypeError`) **and it was the ONE
   mutant that survived the delivered suite.** Now pinned by a characterization test that is its
   only killer. The decision is not re-opened — the ticket's `## Out of scope` and AGENTS.md rule 8
   both put it out of scope — but a decision whose violation is silent needs a test, not a comment.

## NO E2E WAS WRITTEN, AND NONE COULD BE

Stated plainly because a quiet omission here would be the same fault as a skipped test:

- `AGENTS.md` `### E2E` is **`UNKNOWN - verify`**, with the reason recorded in the file itself — no
  runnable game until `EPIC-006`, and `quality.ui_e2e` is `ui-or-critical-path` against a project
  with no UI surface.
- `Dev / run` is `UNKNOWN - verify` too: **there is no CLI entry point**.
- **Nothing imports `src/render.ts`**, so there is no caller to drive even in-process.

`renderBoard` returns a frame as a value and writes nothing, which is exactly what makes
`EPIC-006`'s pipe-driven end-to-end test possible **later**. The first ticket that can carry a real
end-to-end assertion for this module is **`ABC-018`**, where the frame meets stdout. No fake E2E was
invented to fill the slot, and `quality.mandatory_gates` — `lint`, `typecheck`, `unit`, `build` —
does not include one.

## Handed forward — for `ABC-018` and `RISK-005`

- **The East-Asian-Width ambiguity of `U+2654`–`U+265F` is carried forward unchanged** and is
  **`UNKNOWN - verify` on this gate's instruments**. The Engineer's framing is right: every criterion
  in this ticket is written against the frame **as a value**, and as a value the geometry is now
  proven constant in both UTF-16 units **and code points** across all 24 cells. A string width and a
  terminal COLUMN width are different things, and no in-process test reads the second. It lands
  where `4b`'s erase-to-end-of-screen meets a real terminal.
- **The constant geometry `ABC-018` composes against is 9 rows × 18 characters**, and it now holds
  over a wider input domain than the standing FEN table: the empty board, the fully-occupied board
  and every position in the table, in both modes and both orientations.
- **A frame contains no control byte**, proven as a property. `ABC-018` owns the cursor control and
  the erase sequence, so it is the ticket where that stops being true by design — and where the
  message region introduces the escape-sequence trigger this ticket does not have.
