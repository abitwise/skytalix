# AR-1 drift fix cut as `ABC-198` (Ready, XS, P2, DoR 10/10): a lock-only, in-range bump of the `vitest` family to 4.1.12 and `vite` to 7.3.7, with `package.json` unchanged. The vite pairs go IN the same ticket. After the merge, the Release Manager re-states AR-1 on the 3-pair set

The readings are in this task's observation note. I cite `ABC-198`'s `## Scope` and `## Acceptance` as authoritative. Under the owner delegation `…5aaf7cec`, BA/PM rules the scope. Nothing here changes a requirement, so nothing is escalated.

## Scope ruling
- **Lock-only, no range moves.** `@vitest/mocker` 4.1.12 cannot move alone: `vitest` 4.1.11 pins it exactly. So the bump is the `vitest` family (`vitest` + 8 `@vitest/*`) 4.1.11 → 4.1.12, all inside `~4.1.11`.
- **One command:** `npm install --package-lock-only --ignore-scripts 'vitest@~4.1.11' '@vitest/coverage-v8@~4.1.11' 'vite@~7.3.6'`. The specs equal the declared ranges, so `package.json` is written back unchanged (measured).
  - A named `npm update` moves nothing (measured).
  - A bare `npm update` moves 80 versions (measured), so it is rejected.
- **One test literal is re-pinned:** `ABC-192` `A2`'s `CAPTURE_ARM_READ_ON_VITEST`, and only after `BUMP_RERUN_LIST` (1)–(3) are re-run on 4.1.12. This is the row's designed use, not a scope creep.

## The vite pairs: IN, not accepted
- An in-range, lock-only bump exists: `vite` 7.3.7, inside `~7.3.6`. Its entry moves `version`, `resolved` and `integrity` only.
- All 5 vite advisories are `<=7.3.6`, so the 2 new pairs and the 3 approved ones go together (measured: audit 10 pairs → 3).
- It costs no extra hop: the same clause (a) read and the same gates. A reopen-trigger acceptance would leave a fixable pair open for no saving.
- **Fallback:** if the gates are red with vite and green without it, the builder drops `'vite@~7.3.6'` (V3, numstat `50 50`) and hands back. BA/PM then accepts the 2 new vite pairs as LOW, with this reopen trigger: any vite pair graded `high`, or anything in the repo starting a Vite dev server, `ui`, `api` or `browser` mode.
