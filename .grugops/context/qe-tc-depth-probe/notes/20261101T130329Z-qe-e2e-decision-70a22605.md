# qe-tc-depth-probe pre-registration: what skytalix reaches at `go movetime` 100 / 250 / 500 / 1 000 / 4 000 ms on `main`'s tip, the JIT warm-up at 100 ms, two 20-game self-play sanity blocks (100 ms, 500 ms), Stockfish 19's time to its pick depth at E 1 910…2 600, and the SPRT arithmetic. A reading for ADR-0056 C2, not graded.

QE/E2E, task `qe-tc-depth-probe`. Written and sealed **before any timed run**. Owner question (`…f7a50e95`): "would
100 ms be enough to validate algorithmic improvements?" Since the claim, the owner set (`…2896c6eb`, main `8efbb827`):
no SPRT; 100 games at 100 ms per strength change, 400 games at 100 ms per epic, with Stockfish's move time "set from
qe-tc-depth-probe so its pick depth holds". This probe reads the facts both rules need. No verdict, no grading.

## 1. What is under test
- **Build: `main`'s tip `8efbb827`.** The brief named `38c787be`; `main` moved one docs-only commit since
  (`git diff --stat 38c787be 8efbb827 -- src data tools` is empty). Scratch clone (session scratch, outside the
  checkout) detached at `8efbb827`: `npm ci` rc 0, `npm run build` rc 0. The engine is `dist/uci.js` under Node
  v26.12.1.
- **Engine facts used:** the default `Skill Level` is 5 (budget cap 4 000 ms, blunder rate 0), `TimeMode` default
  `level`, so `go movetime X` searches `min(X, 4 000)` ms. The transposition table is cleared at every `chooseMove`
  entry (`src/engine.ts`), so a warmed process carries only JIT/heap state between searches. One `info depth D score …
  nodes N time T nps R pv …` line is printed per search, then `bestmove`; D is the completed depth.
- **OwnBook:** off for every probe search (`setoption name OwnBook value false`), so the start position is searched.
  The sanity blocks keep the default (on), as `tools/rating/rating.ts` runs it.
- **Tools:** `cutechess-cli` 1.5.1, sha256 `dc776901…` (= `ABC-204` pin); Stockfish 19, sha256 `c78c22a9…` (=
  `rating.ts` `STOCKFISH_SHA256`); `openings.epd` sha256 `0d7f7a72…2666` (= `OPENINGS_SHA256`). Paths come from a mode
  600 env file in session scratch; no host path enters a record (ADR-0049 d4).
- **Host:** AMD Ryzen AI 9 HX 370, governor `powersave`, 24 logical CPUs, width 1 (one engine search or one game at a
  time).

## 3. The blocks, in this order (width 1; one wait-clear before each)

Play total ≈ 25–39 min, hard caps sum to 45 min, inside the brief's ≤ 45 min. Waiting is not play. A block that
reaches its cap is stopped by SIGTERM and read on what completed (named as CAPPED).

- **Driver** `raw/scripts/probe.mjs`: wall time is `process.hrtime` from writing `go` to reading `bestmove` (the
  GUI's view); overshoot = wall − budget. The engine's own `time` is recorded beside it. Host fields (foreign vitest
  count, Tctl, load1) are read per search before `go`, outside the timed window.
- **Stockfish pick depth:** D = 1 + int(level), level = clamp(((37.2473·e − 40.8525)·e + 22.2943)·e − 0.311438, 0, 19),
  e = (E − 1 320)/1 870 (ADR-0056 D5 dated block, from `sf_19` `search.h`). `go depth D` stops the search once depth D
  completes and the skill pick is made there; its wall time is the time to the pick depth. Stockfish searches
  MultiPV ≥ 4 with skill on; that cost is inside the reading.
- **Sanity command** (`raw/scripts/sanity.sh`): `rating.ts`'s skytalix engine shape on both sides (same build): `st=<s>
  timemargin=<5 000 − budget> restart=on`, `-each proto=uci`, `-openings file=openings.epd format=epd
  order=sequential -repeat`, `-games 2 -rounds 10 -concurrency 1 -maxmoves 200 -pgnout … -debug all`.
- **Wrapper** `raw/scripts/block.sh`: wait-clear = no foreign `[/]vitest` for 120 s, polled every 10 s, give up at
  1 800 s and proceed NOT-CLEAR (logged, never killed). A sampler every 10 s logs Tctl, frequency, load1 and the
  vitest count; every 60 s a busy scan logs every process ≥ 50 % CPU, owner = probe when its cwd is in the probe's
  scratch, else foreign. **Thermal stop:** with ≥ 30 probe-wide samples, a Tctl median > 85 °C sends SIGTERM.

## 4. What is read (metrics fixed now)
- **R1 per control (fresh):** completed depth median / min / max; nodes median; nps median; wall overshoot median,
  p95, max; over all 25 positions, and named vs sampled.
- **R2 warm-up:** per position, warm/cold nodes ratio and depth difference at 100 ms; median ratio, how many
  positions gain ≥ 1 ply. Also cold overshoot vs warm overshoot.
- **R3 noise:** the spread (min–max) of nodes and depth over the 3 fresh repeats per named position at 100 ms.
- **R4 sanity blocks:** W/D/L, draw ratio, mean plies; time forfeits as cutechess reports them; per searched move
  (book moves excluded: a reply after `info string book`) the overshoot = t(`bestmove` received) − t(`go` sent) −
  budget from the debug log's ms timestamps, median / p99 / max, and the count over budget + 0 / 10 / 25 / 50 / 100 ms
  ("would forfeit at timemargin m"); games/hour = 3 600 × games / (last game end − block start).
- **R5 Stockfish:** per E, D, and the p50 / p95 / max wall to depth D; **the move time needed = the p95, rounded up
  to the next 10 ms** (pick depth reached in ≥ 95 % of the 40 positions); also ADR-0056 C1's rule (≥ 4 × p95, floor
  0.5 s) for comparison, and how many positions exceed 100 ms.
- **R6 SPRT arithmetic** (`raw/scripts/sprt.py`, estimate): logistic Elo, trinomial with a fixed draw ratio, α = β =
  0.05, Wald OC/ASN plus a seeded Monte Carlo check; bounds [0,10], [0,30], [0,50] at true Elo −½·e1, 0, ½·e1, e1,
  2·e1; hours at the measured games/hour of R4 (100 ms and 500 ms). Draw ratio: the pooled draw ratio of R4's 40
  games, and 0.30 (ADR-0056 C2's assumption) beside it. Also the 95 % half-width of the owner's fixed 100 and 400
  games.

## 5. Admissibility (no grading; this marks what the numbers mean)
- **Search and Stockfish rows:** a row is CLEAN when its vitest count is 0 and no foreign busy line falls in that
  block's minute; else SHARED. Each R1/R2/R5 figure is reported over all rows and, where SHARED rows exist, over CLEAN
  rows too. A cell with < 50 % CLEAN rows is marked SHARED (nps a lower bound, overshoot an upper bound).
- **Sanity blocks:** CLEAN when 0 of its samples show a foreign vitest or a foreign busy process; else SHARED with
  the fraction. Games/hour under SHARED is a lower bound.
- A thermal stop or a cap is reported as such; nothing is re-run inside this probe beyond the rehearsal.
