# `AGENTS.md`'s condensed `## Test and UAT authority` drops one historical sentence with no designed pointer

The pre-restructure `AGENTS.md` (`0bf562f`) carried, in `## Test and UAT authority`: *"Tickets
closed before `ABC-042` all deferred UAT to `EPIC-006` because nothing was exercisable; `npm run
chess` ended that reason."* The restructured `AGENTS.md` (reviewed tree) does not carry this
sentence, and nothing in the condensed section points a reader at it.

The fact survives, but not by design: `memory-bank/60-progress.md:707` states the same fact under
a different heading ("UAT is no longer deferrable and is the binding constraint"), which
`AGENTS.md`'s `## Test and UAT authority` pointer does not name. This is history explaining *why*
UAT stopped being deferrable, not an owner directive, exception, number or named-owner ruling a
role acts on, so it falls outside `A2`'s own enumerated minimum. Recorded so the drop is visible
rather than silent — not scored as an `A2` gap.
