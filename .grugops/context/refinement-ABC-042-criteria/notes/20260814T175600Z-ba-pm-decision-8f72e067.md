# The ten owed criterion repairs, each with the clause as it stood, its replacement, and the build it now catches

**No code is owed by any of it.** Ten changes: `RF-1`…`RF-5` from Security/NFR (`RF-6` is the
Orchestrator's — see the observation on what I could not repair) and four from Architect/Design's census.
All ten landed in `plans/tickets/ABC-042-…md`. Wording and naming are mine; the rulings are theirs.

---

## `RF-1(a)` — HIGH, the blocker. ASVS **V2.2.1 [L1]**. Owner BA/PM. → `A6`

**Was:** *"`A6` … **Given** each of `--difficulty 3`, `-x`, `--colour purple` and `foo`, **then** a usage
message naming the offending argument is written, the exit code is non-zero, and zero frame rows are
written."*

**Now:** `A6` is three parts. (i) the accepted set is exactly `## Scope`'s closed table, asserted at the
resolver; **(ii) 1000 GENERATED tokens** — printable ASCII, lengths 1–24, shapes `--<word>` / `-<char>` /
`<word>` / `--colour <word>`, filtered to exclude every accepted spelling — **every one rejected with the
offending token named, zero accepted, zero spawns**; (iii) the four literals, spawned, end-to-end. `##
Scope` also gained **THE ACCEPTED SET, CLOSED**, so the complement is well defined rather than implied.

**Could previously have shipped:** a resolver that quietly recognises `--debug` or `--engine-path` — green
on every criterion and every bar, because four literals of an infinite complement is a denylist.

## `RF-1(b)` — the resolver was not the exclusive validator. Owner BA/PM. → `A9`(2)

**Was:** exclusivity lived only in `## Scope` prose — *"It is the only place that reads `process.argv`"* —
and no criterion bound it.

**Now:** `A9`(2): **`process.argv` occurs exactly once in the delivered production modules — in the entry
point — and its only use is as the argument to the resolver** (ASVS **V2.2.2 [L1]**).

**Could previously have shipped:** an entry point that branches on `process.argv` again *after* the
resolver returns — a second, unvalidated input path, passing every criterion.

## `RF-2` — bar 2's first disjunct was UNREACHABLE. Owner BA/PM. → bar 2, **DELETED**

**Was:** *"every echoed byte is **either passed through `assembleFrame`'s sanitizer**
(`src/frame.ts:123-132`) or the message contains zero C0 … and zero `\x1b`"*

**Now:** the `assembleFrame` disjunct is **deleted, not re-worded**; the byte-level property is the sole
operative one. (`sanitize` is module-private, `src/frame.ts:123`, and its only public route composes a
whole frame — which `A5`/`A6` forbid on the rejection paths. It was also the weaker control: `R-A` records
that C1/CSI survives `sanitize` in `unicode` mode.)

**Could previously have shipped:** nothing worse in behaviour — but a reader could satisfy the bar by
claiming a route no legal build can take, which is how a dead clause becomes a false pass later.

## `RF-3` — the operative disjunct rejected every conventional build and could pass vacuously. Owner BA/PM. → bar 2

**Was:** *"the message contains **zero** C0 control characters and zero `\x1b` — asserted byte-level over
an argument containing `\x1b[2J`"*

**Now:** spawn once with a token containing a literal `\x1b[2J`, **capture BOTH stdout and stderr**, and
assert in order: **(i) non-vacuity first** — the token's printable characters are present; **(ii)** the
**echoed token's** bytes contain zero C0, zero `U+007F`, zero `\x1b`; **(iii)** zero frame rows.

**Could previously have shipped:** three builds. A newline-terminated usage message (`\n` is a C0) failed
the criterion as literally worded; a build whose message does not echo the argument at all **passed
vacuously**; and a `console.error` build was invisible to a stdout-only assertion.

## `RF-4` — bar 3 was written in a spelling this repository never uses. Owner BA/PM. → bar 3

**Was:** *"**No filesystem and no network.** Zero `fs`, `net`, `http`, `dns` imports in the delivered
diff."*

**Now:** a **grammar** over static **and** dynamic specifiers —
`/^(node:)?(fs|net|http|https|tls|dns|dgram)(\/|$)/` — **plus** zero occurrences of the no-import globals
`fetch`, `WebSocket`, `XMLHttpRequest`; scoped to production modules, with the test file exempt (BAR 1b).

**Could previously have shipped:** `import { readFileSync } from "node:fs"` — satisfying bar 3 exactly as
worded, since 0 of 47 files here use a bare specifier. And any network call at all: `fetch` is a bare
global on Node 22 and needs no import. The same defect has **already shipped a false pass in this repo**
(`src/glyph-mode.nfr.test.ts:52-55`, the `node:fs/promises` mutant that passed all 271 tests).

## `RF-5` — the scope ruling lived only in a context note. Owner BA/PM. → the security section

**Was:** bar 1 and the firing threshold stated no file scope at all.

**Now:** **SCOPE OF THE BARS, RULED** is written on the page (bars 1 and 3 and the builtin clause are
scoped to the delivered PRODUCTION modules), and **BAR 1b** is added verbatim: the test file may reach
`node:child_process` only in argument-array form, zero `exec`/`execSync`, zero `shell:`, no
string-concatenated spawn argument.

**Could previously have shipped:** nothing — the opposite. As worded, **every** build satisfying `A1`
violated bar 1, and the merged, green, security-POSITIVE precedent the ticket cites by name became
retroactively illegal. Also: the one file that may actually spawn was ungoverned.

## Census row 1 — `A5`'s zero-rows assertion named no channel. Owner BA/PM. → `A5`

**Was:** *"**zero** frame rows are written"*
**Now:** *"**zero frame rows are written ON STDOUT AND STDERR, UNIONED**"*
**Could previously have shipped:** a build that writes the board to the *other* channel and then complains
— test note 4's own failure mode surviving the criterion that exists to catch it.

## Census row 2 — `A6`, identical defect, same sentence. Owner BA/PM. → `A6`(iii)

Same replacement, same shipped build. The two rows shared the defect because they shared the phrase.

## Census row 3 — `A9` said "file" then "module". Owner BA/PM. → `A9` scope

**Was:** *"the entry point is the only **new** file containing `process.stdout` … and no other new
**module** contains `process.` at all."*
**Now:** the whole of `A9` is scoped to **new PRODUCTION modules** (`ADR-0011` clause 1: a `.ts` under
`src/` that is not a `.test.ts`), which is the ruled reading; the criterion is stated as three numbered
clauses.
**Could previously have shipped:** nothing — as worded it **rejected** the delivered build: the test file
must spawn via `process.execPath`, so under the widest reading of "module" every build satisfying `A1`
broke `A9`. Same class as bar 1 vs `A1`.

## Census row 4 — `A10`'s two halves contradicted each other. Owner BA/PM. → `A10` **deleted clause** + new `A12`

**Was:** *"`git diff --numstat` shows the entry point, the resolver, **their** test file(s),
`package.json` and `AGENTS.md`, and **nothing else**. … Suite green, skip **0**; **`src/` otherwise
byte-identical**."*

**Now:** `A10` keeps only its true purpose — the distribution decision measurably unmade, `package.json`
asserted key by key against `HEAD`. The file-list and byte-identity clauses are **DELETED, not re-worded**,
and their surviving property is re-homed in a new, honestly-scoped **`A12`**: the diff shows exactly the
new files, `package.json`, `AGENTS.md` **and `src/history-pane.nfr.test.ts`**; **all 18 merged PRODUCTION
modules are byte-identical**; the only merged-file change is `LICENSED_DRIVERS` (`:213`) **+1 element plus
its citation line**; suite green, skip 0.

**Could previously have shipped:** nothing could ship. Every build satisfying `A10`'s file list left the
licence stale and failed `A10`'s own "Suite green"; every suite-green build touched a file `A10` required
to be byte-identical. The ticket was unbuildable as written.
