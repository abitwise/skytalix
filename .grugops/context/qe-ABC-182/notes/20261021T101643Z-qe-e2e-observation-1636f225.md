**Breaking the harness (scratch only).**
1. **Usage.** 3 arguments, or a missing instrument: exit 2 with the usage line. Correct.
2. **A plant that does not apply.** `<tip>` = `619abc14` (no `src/book-file.ts`): exit 2,
   `plant P2b did not apply at 619abc14`. Correct.
3. **A relative instrument path** (`clause-b.folded.mjs`, run from its own directory): exit **1**. The header prints
   `instrument sha256 ` (empty), and node fails after the harness `cd`s into the clone. No plant is named. The usage
   line asks for an absolute path, but the header says exit 1 "names each mismatched plant". See `QE-182-b`.
4. **One edit of a two-edit plant misses (P2c).**

     P2c's `cli.ts` substitution no longer matches.
   - The harness, given that clone and tip, exits **0** and prints `P2c … path: string, from cli.ts options … ok`.
   - The plant commit changes only `src/book-file.ts` (1 file, 2+/2−).
   - `mk` refuses only a plant that changed nothing. A partially applied plant therefore runs under the full plant's
     label. See `QE-182-a`.
