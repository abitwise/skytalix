## K3 (`G2`, ≤ 1.05 ×), graded
- **Arms**, all imported into **one** `node` process per session, each from `git archive` into its own scratch dir (`src/` + `package.json`):

  - **H, the graded arm:** `grugops/ABC-271` code commit `10f29a82`, `src/` tree `08e56302` (= the branch tip's). Entry: `evaluateAtPhase`.
- **Instrument (`raw/scripts/g2.ts`; `qe-ABC-270`'s `g2.ts` timing loop, unchanged):** the six perft roots; N = 200 000 calls per root per round; 6 rounds. Rounds 2, 4 and 6, counted from 1, reverse the session's arm list; round 1 is the dropped warm-up. Each arm's statistic is the mean over rounds 2–6 of its mean over the six roots, in ns per call. Every arm is called `ev(position, phase)` with `phase = phaseOf(root)` (H's), computed once per root before timing; a running sink.
- **Session order:** session 1 lists **[B, C, H]**; session 2 lists **[H, C, B]**.
- **Statistic and verdict:** r_s = mean(H) / mean(B); **R = (r₁ + r₂) / 2; MET iff R ≤ 1.0500**, compared unrounded, printed to 4 dp. No third session, no tie-break.
- **Void rule, on C alone:** c_s = mean(C) / mean(B) on the roots outside **[0.970, 1.030]** voids that session. It is re-run once, in its own recorded window, in the same order. A second void in the same slot is a **STOP to Architect/Design** with every reading attached: no K3 verdict and no further session.
- **The host gate (the temperature gate this brief asks to name):** each session starts only after `host.mjs`'s `waitClear` (byte-identical to `qe-ABC-268`'s) reads 0 foreign vitest, 0 cutechess-cli, load1 ≤ 2.0 and **Tctl ≤ 60.0 °C**, polling 15 s for up to 60 min. **Not relaxed.** If it does not clear, the slot has no K3 reading (`UNKNOWN - verify`), and a new window needs a new sealed dated line. Once a session starts nothing interrupts it, and the gate voids nothing.
- **Nothing else voids, adds or drops anything:** no load threshold beyond the gate, no extra session or round, no dropped root, round or outlier, no re-read after a verdict.
- **The spread, a report (grades nothing):** each r_s, |r₁ − r₂|, and each arm's per-round min–max over rounds 2–6, against `qe-ABC-269`'s reference spread **0.037** in r. If |R − 1.0500| ≤ 0.037 the verdict line adds "within one session spread". MET stays MET; a miss stays a miss.
- **Host, per session:** one `flock <scratch>/host-test.lock` hold per session (the gate, `G2`, its nps reports). One core. Recorded at the start, after `G2` and at the end: `date -u`, `uptime` (load1), the top five CPU users (`ps`), Tctl; plus `node --version` and the trees. A foreign process that is not a test, build, engine or game run (for example `abtop`) is recorded and never touched.
