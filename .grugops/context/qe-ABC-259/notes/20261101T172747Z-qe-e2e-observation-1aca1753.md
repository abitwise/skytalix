- **QE-259-a (MEDIUM, non-blocking; carrier BA/PM, then the Architect).**
  - **Hole:** the environment rule matches `process.`, `argv` and `import.meta.env`. `import { env } from "node:process"` followed by `env.X` is idiomatic Node ESM, and it contains none of the three, so Q5 survives.
  - **Why it is not blocking:** the row implements the ticket's rule exactly, so no criterion fails.

  - **Remedy:** one regex term, for example `\bprocess\b` (or `node:process`) in place of `process\.`. It has 0 hits in the stripped code of the five files today, so A1 would hold. It needs a ticket that widens the rule, which is a criteria change for BA/PM.
- **QE-259-b (LOW; carrier BA/PM).**
  - **Hole:** A8's strip regex does not know about strings. A `/*` inside a string or regex literal starts a "comment" that runs to the next real `*/`, which can hide many lines of code (Q6). A `//` inside a string hides the rest of its line (Q7).
  - **Today:** no literal in the five files holds `//` or `/*`, as the SE probed and QE re-probed. So A1 and A5 are sound now.
  - **Remedy:** either a guard row that fails if any of the five files' string literals holds `//` or `/*`, or blanking string literals before the strip.
  - **Scope:** the same weakness sits in A8 (ABC-087) itself.
- **QE-259-c (LOW, a known scope limit, as the brief anticipated).**

  - **Why it stands:** Q3 is outside the ticket's scope, since the row does not police reads of the deadline. Even so, `deadline - start <= 100` is functionally the forbidden 100 ms branch, and only review catches it.
  - **What is caught:** a destructured alias (Q1) is caught, because the line still holds `budgetMs`.
  - **Note to carry:** the text scan cannot close this class without an AST, which is out of scope. Record it as a review habit on ABC-251, which rewrites the scanned search next.
