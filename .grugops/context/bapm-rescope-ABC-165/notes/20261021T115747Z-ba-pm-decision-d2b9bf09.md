# Forward trace-row rule: every appended row fills the table's 10 columns in header order; the Orchestrator appends only if `A1`'s output does not change

**Ruling.** A row appended to the table in `plans/traceability.md`, by any hop and from any done record, has exactly
the table's 10 cells, in header order:

`| {ticket} ({hop}) | {what this hop did, one line} | {EPIC-nnn or —} | {F-nnn or —} | {NFR, ADR, AR and finding ids, or —} | {branch @ sha<br>files touched, or —} | {gates and test counts, or —} | {UAT verdict or waiver, or —} | {release tag, or —} | {column move or verdict} |`

1. Write `—` for a cell with nothing to say. Never leave a cell out.
2. Write a literal `|` inside a cell as `\|`. That includes code spans: GFM splits on an unescaped `|` even there.
3. Join two facts in one cell with `<br>` or `; `, never with `|`.
4. **Pre-append check (the Orchestrator):** run `A1` (`ABC-165` § Acceptance) before and after the append. The two
   outputs must be equal. Appends land at the end of the table, so a good row changes nothing. Until `ABC-165` and
   `ABC-185` merge, the "before" list is not empty. After both merge it is `[]`.

**Who carries it.**
- **Orchestrator, from its next brief:** every brief's Publish section asks for the trace row in this template, and
  every done record carries it that way. The Orchestrator is the single appender. A done-record row that fails the
  check is not appended as-is. The Orchestrator re-cells it into the template with no word changed, or returns it.
  It never appends a failing row.
- **`plans/traceability.md`'s own note** (the paragraph at `:377-378`): `ABC-165` Scope 2 writes the rule, the
  template and the count there, and names no row by id. This is the authoritative home in the repository.
- **`AGENTS.md` through the Scribe: the Orchestrator decides.** `AGENTS.md` has 16 B of headroom (24,560 of
  24,576 B; `src/cli.test.ts:2484`). The template does not fit. At most a pointer fits: for example, the 15 bytes
  ` (10 cells/row)` appended to `- Traceability: \`plans/traceability.md\`` (`AGENTS.md:181`) leaves 1 B. Anything
  longer needs the Scribe to free bytes elsewhere. The brief plus the trace note already reach the only appender, so
  the pointer is optional.

**Options not taken.**
- **A separate hop table with its own shape.** Every existing hop row would have to move tables (a removal under
  `A3`), or the file would hold two conventions. `A1` would then need to count per table. The 10 columns already
  have a slot for everything a hop row says: the branch goes in Code, the gates in Tests, the verdict in Status.
- **Checking only the appended line.** Comparing the whole-file list before and after is the same check written
  once, and it catches a slip anywhere in the append.
