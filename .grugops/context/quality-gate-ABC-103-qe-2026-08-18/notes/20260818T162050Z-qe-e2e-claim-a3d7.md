# WHAT THIS HOP COULD NOT PROVE — recorded as a soft claim, because it is not measured

1. **That the mutant set is complete.** Seven mutants is a sample, not a proof. The set was chosen
   around one property (what changes the flat/nested module listing) and a competent wrong build
   outside that property is untested by construction. **`confidence: medium` on "no other survivor
   exists"; `high` only on the seven verdicts actually run.**

2. **That `G1` will actually bite.** The claim that `EPIC-006` adds a `cli`-prefixed module is a
   forecast from the epic's subject and from `ABC-101`'s shape, not a measurement. `M1` proves the
   row reds for such a module; it does not prove one is coming.

3. **That `G2`'s loss matters to anyone.** No incident is on record in which a production module
   vanished. `M2` proves the detection was there and is gone; it does not prove the detection was
   ever worth its four false alarms. **A reader who concludes `ABC-103` was still net-positive is
   supported by this hop; a reader who concludes the count should come back is not.**

4. **That the added `lstatSync` row is portable.** It was run on darwin/APFS only. On a filesystem
   or checkout tool that materialises tracked files as links — some CI caches, some Windows
   configurations without developer mode — `isFile()` on a real checkout is **UNKNOWN - verify**.
   This repository has no CI and runs locally only (`ADR-0007`), so the exposure is nil today and
   would surface the day `EPIC-006` adds one. Named rather than discovered later.

5. **Whether `G3` should be repaired at all.** Narrowing the `nested` equality to the entry point
   would end its false alarm on nested test files and simultaneously **surrender `ADR-0011` `R3`'s
   trigger detector**, which is the more valuable half. This hop reports the tension and does not
   resolve it — it is BA/PM's and Architect/Design's, and it is the same trade `ABC-105` is about.

6. **Anything about performance.** No `N8-LANE` measurement was taken and none is claimed. This hop
   adds zero test FILES and one assertion, so the per-file floor does not apply; the suite ran
   2.13 s wall against a 2.44 s baseline reading, which is **noise, not a measurement**, and is
   recorded here only so nobody mistakes it for one.
