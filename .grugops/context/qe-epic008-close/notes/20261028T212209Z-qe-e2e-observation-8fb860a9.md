## Host rule
- **Power, logged once:** at this note this host has **no `/sys/class/power_supply` entries** (no battery, no adapter entry), so "every reading runs on AC" holds by construction. Each precondition poll and each 10 s sample re-reads it. A battery entry at a precondition poll is a STOP before game 1. A reading is never stopped once started.
- **Preconditions before each reading starts:** load1 ≤ 8, 0 `node … vitest` processes, 0 `cutechess-cli` processes; polled every 15 s for up to 60 min (a pause, never a re-run). Not met → stop and hand back.
- **Sampler every 10 s** during each reading: load1, power, CPU temperature (k10temp), the foreign `node … vitest` count, and the count of `cutechess-cli` processes that are not this reading's.
- **Overlap accounting:** a game overlaps if its [GameStartTime, GameEndTime] meets a window of contiguous samples with foreign vitest > 0 or foreign cutechess > 0, padded 10 s. Games touching a load1 > 8 sample are counted too. **Reported for each reading: all games (the reading, as the page states) and overlap-free and load-free subsets** (QE's port of cutechess `elo.cpp`, checked equal to the tool's own line on all games). The subsets are reported, not graded.
- QE-owned checks, reported: `[FEN]` colour pairs per round; book-move counts; `go`→`bestmove` gap per engine (median, max, count over budget + 31 ms); move-cap draws; stderr sizes; wall (median game, games/h, span) = this host's `A6` rate.
