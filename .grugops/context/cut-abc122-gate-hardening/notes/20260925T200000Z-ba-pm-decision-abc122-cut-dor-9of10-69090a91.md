# `ABC-122` cut: gate hardening (K4 bounded-time test command, K3 direct capacity-guard test)

Hand-authored, no `seal` — the degraded posture `AGENTS.md` records; not re-derived here.

## What was cut

One `S`, `P1` ticket, `plans/tickets/ABC-122-gate-hardening-bounded-timeout-and-capacity-guard-test.md`,
bundling `ABC-081`'s two named gates gaps into a single ticket on the Orchestrator's
recommendation and the owner's word (*"go, cut the hardening ticket and run it through"*):

- **K4** — a Node-only wrapper (`node:` built-ins only, no `timeout(1)` dependency) that bounds
  `npm test`'s wall time, kills the full process tree on timeout, and exits a distinct non-zero
  code; `package.json`'s `test` script points at it. Proven with an armed synthetic-hang fixture
  (short timeout, orphan-process check) that does not itself become a hanging test in the
  default lane, and a byte-for-byte green pass-through proof.
- **K3** — a direct test of the `ply >= KEY_ARRAY_CAPACITY` guard in *each* of `src/search.ts`
  and `src/engine.ts`, independent of the root depth guard (`ABC-081` decision 6a) standing, plus
  a mutant on each guard watched RED.

## Overlap check (queue task's own instruction)

Read each of `ABC-050`, `ABC-105`, `ABC-108`, `ABC-110`, `ABC-118`'s own `## Scope` /
`## Out of scope` at this cut, not just their names:

- `ABC-050` (`In Review`): guards `vitest.config.ts` itself under static tooling — a different
  file, a different failure mode (silent config drift, not a hung/untested guard).
- `ABC-105` (`Backlog`): detects a missing QE verdict note — nothing about the test command's
  own timeout behavior or the search recursion.
- `ABC-108` (`Backlog`, `M`): rules `NFR-008`'s CPU-clause *total*. `ABC-110` (`Backlog`, `L`,

  a hang fails in bounded time — a hang breaches neither clause, it just never finishes.
- `ABC-118` (`Done`): guards the lane's *inventory* (`test.exclude`) against a type-valid glob
  that silently changes what is collected — orthogonal to a timeout wrapper or a capacity guard.

**No overlap. `ABC-122` is independent of all five.**

## Scope/non-scope, in one paragraph each

**Scope**: (1) the wrapper script plus the one `package.json` line it requires; (2) one new
direct test per file (`src/search.ts`, `src/engine.ts`) of the `KEY_ARRAY_CAPACITY` guard, plus
one mutant per file watched RED against it.

**Non-scope**: the root depth guard itself (load-bearing, independently tested, untouched);
`ABC-121` and any search-algorithm change (this ticket lands *before* it, per the owner's word);
`AGENTS.md`'s `### Test` command line (named owed to the Scribe as a follow-up — the queue task's
own instruction); `plans/nfr-catalog.md`, `plans/board.md`, any ADR (fenced from this cutting
hop); a CI job or hook (this project has none).

## Acceptance criteria (one line each)

- `A1` — the wrapper kills the whole tree on timeout and exits a distinct non-zero code, within
  timeout + ≤ 250 ms.
- `A2` — a fast, green command passes through the wrapper byte-for-byte unchanged.
- `A3` — an armed synthetic-hang fixture proves the RED path (short timeout, orphan check),
  without hanging the default lane it is proven in.
- `A4` — `npm test` invokes the wrapper around `vitest run`, default timeout `N ≥ 5×` the
  measured median lane wall time and `≤ 120 s`, both numbers stated at delivery.
- `A5` — portability stated: `node:` built-ins only, Node/OS version named.
- `A6` — `src/search.ts`'s `KEY_ARRAY_CAPACITY` guard exercised directly, independent of the
  root depth guard, asserted on the return value and a call/write spy.
- `A7` — a mutant on `src/search.ts`'s guard reds `A6`, watched and reverted.
- `A8` — `A6` repeated for `src/engine.ts`'s own guard instance.
- `A9` — `A7` repeated for `src/engine.ts`.
- `A10` — the production (non-test-seam) call path is unchanged; both constants stay `128`; the
  existing suite is green at its prior result plus exactly this ticket's additions.
- `A11` — `git diff --numstat` fence: only `src/search.ts`, `src/engine.ts`, the two new test
  files, `tools/grugops/`, and one `package.json` line; `AGENTS.md`/`nfr-catalog.md`/`board.md`/
  ADRs byte-identical.
- `A12` — all four mandatory gates green through the wrapper; exactly 2 new test files under
  `src/`; `N8-LANE` net CPU reported against the ≤ 650 ms standing bar.
